# Releases

Builds of the apps below. Each release is tagged `<app>-v<version>` (`mod-v…`, `server-v…`). Its assets are one ZIP per supported platform, named `<App>-<Platform>.zip`, each with a `.sha256` file. Download the ZIP for your platform, extract it to a writable folder and run the app. The apps check this repository for updates only when you ask them to.

Each app below links to its user guide, the one shipped in its latest release.

## Cannae Mod

A Windows desktop and command-line APK patcher for one supported build of a specific Unity Android game. Select the original game files and the address of the companion server, and it produces one signed APK. The server is a separate project; this application does not run it.

[User guide](mod/README.md)
